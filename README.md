# Katida Kosma Agentejo
This is a translation for Kitten Space Agency into Esperanto.

**Updated for KSA: v2026.6.2.4531**

## Installation
1. Download the [latest release of the translation](https://github.com/DavidK0/KatidaKosmaAgentejo/releases/latest) (a single Gauges.xml file)
2. Replace `Kitten Space Agency\Content\Core\Gauges.xml` with the one you downloaded

## Translation principles

* When possible, I prefer the [simplaj samsignifaj vortoj](http://bonalingvo.net/index.php/Simplaj_samsignifaj_vortoj)
* Even when a word does not appear in that list, I try to follow the same general approach. For example, I prefer 'cxeapsido' over 'periapso'.
* I avoid anglicisms and prefer more native Esperanto wording. For example, I prefer 'sxalti' or 'eki' over 'aktivigi'.
* Because Esperanto is meant to be an easy language to learn, I prioritize picking accessible words over technical sounding word. For example, I prefer 'antaux' instead of 'progrado'.
* *Kitten Space Agency* does not support foreign character sets, so I stick to cx, gx, jx, ux, and sx instead of using diacritics.
