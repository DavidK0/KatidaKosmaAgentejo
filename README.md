# Katida Kosma Agentejo
This is a translation for Kitten Space Agency into Esperanto.

# My guides and philosophies

When possible, I prefer the [simplaj samsignifaj vortoj](http://bonalingvo.net/index.php/Simplaj_samsignifaj_vortoj)

Even if a word can't be found on the simplay samsignifaj vortoj list, I still will follow its philosphy, for example by using 'cxeapsido' instead of 'periapso'.

I avoid anglicisms and prefer original Esperanto words. For example, I prefer 'sxalti' or 'eki' instead of 'aktivigi'.

Esperanto is about making language learning easier, so we should prefer easy words over words that might sounds more technical. For example, I prefer 'antaux' instead of 'progrado'.

Kitten Space Agency does not support foreign character sets, so I stick to cx, gx, jx, ux, and sx instead of using diacritics.
